# PalmCare — تطبيق ميداني لإدارة علاج النخيل من سوسة النخيل الحمراء (PWA)

تطبيق ويب تقدمي (PWA) يعمل **بدون إنترنت بالكامل** على آيفون (وآندرويد)، مخصص لفني ميداني يعالج نخيل مصاب
بسوسة النخيل الحمراء في مناطق ضعيفة التغطية. المعلومات تُخزَّن محلياً على الجهاز وتُزامَن للخادم تلقائياً
بمجرد توفر الاتصال.

## التشغيل على الجهاز

1. انقل مجلد المشروع إلى أي استضافة HTTPS (أو استضف محلياً عبر HTTPS أثناء التطوير):
   - معاينة: `npx serve .` ثم افتح `http://localhost:3000`
   - **ملاحظة آيفون:** يجب تقديم التطبيق عبر **HTTPS** حتى يمكن تثبيته على الشاشة الرئيسية وقراءة GPS والكاميرا.
2. افتح الموقع في Safari ثم اضغط زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
3. زر «استيراد إكسيل» ← اختر ملف الدفعة الأسبوعي المستلم عبر واتساب (`samples/week-import.xlsx` عينة).

## المزايا

- **استيراد إكسيل بدون إنترنت**: تحليل محلي كامل، ربط أعمدة تلقائي (مع شاشة ربط عند تغيّر التنسيق)،
  دمج المزارعين بالهوية/الجوال، تنبيه الصفوف ذات الإحداثيات الناقصة أو غير المنطقية، وكل دفعة ترتبط بأسبوعها.
- **GPS حيّ**: التقاط الإحداثيات بضغطة واحدة من شريحة GPS (تعمل بدون شبكة)، مقارنة مع إحداثيات الإكسيل
  وتنبيه عند فرق كبير، إدخال يدوي احتياطي، وحساب المسافة/الاتجاه لأقرب مزرعة مستحقة الفحص.
- **رسم الحدود**: المشي على المحيط (تسجيل تلقائي كل X متر) أو تحديد 4 أركان؛ المساحة تُحسب تلقائياً؛
  مناطق العوائق تُرسم وتُوسَم داخل الحدود. الخلفية البصرية (بلاطات OpenStreetMap) تُحمَّل عند أول عرض فقط وتُخزَّن محلياً.
- **زيارة خطوة بخطوة**: المزرعة → GPS → العدد الفعلي (تنبيه تلقائي عند اختلافه عن المسجل ويُسحب للتقرير) → العوائق (وسوم جاهزة + ملاحظة صوتية) → إضافة النخيل المصابة → حفظ.
- **النخلة**: كود، إحداثياتها، درجة الإصابة، المبيد/الجرعة من قائمة جاهزة، صورة، تاريخ علاج (افتراضي اليوم)،
  موعد الفحص القادم **يُحسب تلقائياً (تاريخ العلاج + 5 أيام)** بدون إدخال يدوي.
- **متابعة مرمّزة**: رئيسية تعرض الفحوصات المتأخرة 🔴 / المستحقة 🟡 / القادمة 🟢 مع تذكيرات محلية.
- **متابعة النخلة**: فتح السجل كاملاً (اكتشاف ← علاج ← فحص) وتسجيل النتيجة (شفيت / تحتاج علاج إضافي / ماتت) مع صورة مقارنة.
- **تقارير**: بضغطة واحدة PDF (عبر الطباعة) و Excel، مشاركة مباشرة عبر واتساب، ولوحة إحصائيات (نسبة الشفاء، الفروقات، العوائق، أسبوعياً).
- **مزامنة تلقائية**: نسخ احتياطي كامل للسحابة عند توفر الإنترنت (ضبّط رابط خادمك في الإعدادات)، تصدير/استيراد نسخة يدوياً.

## الهيكل

| شاشة | المهمة |
|---|---|
| الرئيسية | فحوصات اليوم + «زيارة جديدة» + «استيراد إكسيل» |
| المزارع | بحث بالاسم/الهوية/الجوال |
| ملف المزرعة | البيانات، الخريطة (حدود+نخيل+عوائق)، الخط الزمني، التقارير |
| خريطة المنطقة | كل المزارع لتخطيط مسار اليوم |

## ملاحظات تقنية (أهمها)

- **التخزين**: IndexedDB محلي لجميع البيانات والصور والحدود؛ Service Worker يخزّن غلاف التطبيق والبلاطات.
- **التذكيرات**: تنبيهات Web Notification تُطلَق عند فتح التطبيق وفي الخلفية وقت توفر «push server» يدعمه iOS.
- **iOS والملفات**: المشاركة عبر `navigator.share` (يعرض واتساب في ورقة المشاركة)؛ PDF عبر حوار الطباعة.
- **خادمك**: اترك حقل الربط فارغاً لتكتفي بالنسخ المحلي، أو أضف `POST` JSON لاستقبال اللقطات الكاملة.

## تطوير

- `samples/make-sample.mjs` يولّد ملف دفعة أسبوعية تجريبي (الصف ٥ يحوي إحداثي ناقص عن قصد).
- المكتبات استُوردت محلياً (SheetJS / jsPDF / idb) لكي يعمل التطبيق بدون أي CDN.
